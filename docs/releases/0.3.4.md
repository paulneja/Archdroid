# ArchDroid v0.3.4

- Chrome, Aurora and Ember visual styles in Settings, saved between launches.
- A richer orb with flowing materials, traveling reflections, precessing rings and drag tilt.
- Animated page transitions, card entrances and press feedback across the app.
- Performance mode uses flat controls and a compact status panel, without shaders, blur, particles, motion sensors or animations.
- System reduced motion also stops decorative movement and loading animations.
- Terminal text can shrink to 1 sp; the compact size menu and pinch gesture still remember the setting.

Signed release APK, complete source archive and SHA256 checksums included. License notices are bundled in the app and source.
